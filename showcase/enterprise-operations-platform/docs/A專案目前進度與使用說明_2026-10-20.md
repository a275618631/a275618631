## 2. 目前已完成的功能

### 後端與資料庫

- ASP.NET Core 10 REST API。
- PostgreSQL 18 persistence 與 EF Core migration。
- 設備讀取：`GET /api/operations/equipment`。
- 工單讀取：`GET /api/operations/work-orders`。
- 建立工單：`POST /api/operations/work-orders`。
- 完成工單：`POST /api/operations/work-orders/{id}/complete`。
- 健康檢查：`GET /health`。
- 工單輸入驗證、設備存在性檢查；前端在送出期間停用建立按鈕。後端尚無通用冪等防重機制。
- 無 PostgreSQL connection secret 時，可使用 in-memory fallback 做 API 開發。

### Auth／RBAC MVP

- JWT Bearer validation。
- JWT issuer、audience、signing key 由 User Secrets 提供。
- JWT 設定不完整時 fail closed，避免未設定時誤放行。
- Development-only `/api/auth/demo-login` 會以 synthetic Demo 帳號簽發 1 小時 JWT。
- `401`：未登入、token 無效或 token 過期。
- `403`：已登入但角色不足。

角色政策：

| 操作 | 可用角色 |
|---|---|
| 讀取設備與工單 | `Viewer`、`Operator`、`Supervisor`、`Administrator` |
| 建立工單 | `Operator`、`Supervisor`、`Administrator` |
| 完成工單 | `Supervisor`、`Administrator` |

### Vue 使用介面

- Development 模式可選 Demo 帳號登入。
- 貼上 Bearer token 後連線。
- 載入設備與工單。
- 建立工單。
- 完成開啟中的工單。
- 顯示 `401`、`403`、validation error 與 API unavailable 訊息。
- Token 只保留在目前頁面記憶體，不寫入 browser storage。

### Backup／Restore

- `pg_dump` custom archive backup helper。
- `pg_restore` restore helper。
- 僅允許 loopback PostgreSQL host。
- Restore 預設關閉，必須明確加入 `-ConfirmRestore`。
- Target database 必須符合 `enterprise_operations_restore_*`。
- 已以 synthetic data 完成 restore 與 source digest 比對。

### 一鍵本機 Demo

- `scripts/start-local-demo.ps1` 會啟動 API 與 Vue、等待 health／port ready，並可自動開啟瀏覽器。
- `scripts/stop-local-demo.ps1` 會遞迴停止 API／npm／Vite 程序樹。
- 啟動器使用 `.local/demo/` 保存暫時 log／PID state；該路徑已被 Git ignore。

## 3. 如何使用

### 前置條件

- .NET 10 SDK。
- Node.js／npm。
- PostgreSQL 18，服務監聽 `127.0.0.1:5432`。
- A 專案 PostgreSQL password 僅存於 User Secrets，不放入 Repo。

### 一鍵啟動 Demo（建議）

```powershell
cd <LOCAL_WORKSPACE_PATH>
powershell -ExecutionPolicy Bypass -File .\scripts\set-local-jwt.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\start-local-demo.ps1
```

停止：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\stop-local-demo.ps1
```

### 手動啟動 API

```powershell
cd <LOCAL_WORKSPACE_PATH>

powershell -ExecutionPolicy Bypass -File .\scripts\set-local-connection.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\set-local-jwt.ps1

dotnet run --project .\src\EnterpriseOperationsPlatform.Api\EnterpriseOperationsPlatform.Api.csproj --urls http://127.0.0.1:5080
```

`set-local-jwt.ps1` 會要求 issuer、audience 與至少 32 UTF-8 bytes 的 signing key；輸入會寫入 User Secrets，不會寫入 Git。

### 啟動 Vue

在第二個 PowerShell 視窗執行：

```powershell
cd <LOCAL_WORKSPACE_PATH>
npm install
npm run dev -- --host 127.0.0.1
```

開啟 Vite 顯示的本機 URL，選擇 Demo 帳號並登入；也可以貼上由核准 issuer 產生的合法 JWT。

Development Demo 帳號：`viewer/viewer-demo`、`operator/operator-demo`、`supervisor/supervisor-demo`、`administrator/administrator-demo`。這些是 synthetic credentials，只能用於本機 Demo。

目前 MVP 的 `/api/auth/demo-login` 只在 Development 映射；沒有正式 `/login`、使用者建立或角色管理服務，不能當成 production identity system。

### 直接測試 API

```text
GET  http://127.0.0.1:5080/health
GET  http://127.0.0.1:5080/api/operations/equipment
GET  http://127.0.0.1:5080/api/operations/work-orders
POST http://127.0.0.1:5080/api/operations/work-orders
POST http://127.0.0.1:5080/api/operations/work-orders/{id}/complete
```

Operations endpoints 必須帶 `Authorization: Bearer <token>`；`/health` 不需要登入。

### Backup／Restore 操作

管理員先建立 synthetic restore database：

```powershell
& "C:\Program Files\PostgreSQL\18\bin\psql.exe" `
  -h 127.0.0.1 -p 5432 -U postgres -d postgres `
  -f "<LOCAL_WORKSPACE_PATH>"
```

建立 backup：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\backup-postgresql.ps1 `
  -OutputDirectory .\artifacts\backup
```

執行 restore：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\restore-postgresql.ps1 `
  -BackupFile <backup-file> `
  -TargetDatabase enterprise_operations_restore_smoke `
  -ConfirmRestore
```

如果 `psql` 不在 PATH，使用上述完整路徑即可；目前 helper 會自動搜尋 `C:\Program Files\PostgreSQL\<version>\bin` 的 `pg_dump`／`pg_restore`。

## 4. 完成度與差異

### 已完成的 MVP 能力

- API、PostgreSQL migration、設備讀取與工單讀取／建立／完成。完整設備／工單 CRUD 尚未完成。
- JWT 驗證與第一個可測試角色授權垂直切片。
- Development-only Demo login 與 Vue 登入流程。
- 一鍵啟動／停止 API 與 Vue 的 Windows PowerShell 工具。
- Vue 基本操作介面與錯誤狀態。
- Synthetic backup／restore drill。
- .NET 與 Vue 回歸證據。

### 尚未完成的正式產品能力

- 正式 Identity Provider 整合。
- 使用者建立、角色管理、權限管理。
- Refresh token、token revoke、key rotation。
- Audit log 與完整操作追蹤。
- CI pipeline、staging／production deployment。Browser E2E 是原 M1 驗收缺口，列於下方近期工作。
- Production Secret Manager、HTTPS、rate limit、正式 CORS 策略。
- Backup retention、排程與定期 restore drill 自動化。

因此目前的差異是：

> 現在是「可在本機驗證的安全 MVP」；不是「已具備正式登入、正式部署與完整企業治理的產品」。
