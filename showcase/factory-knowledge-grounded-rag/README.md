# 工廠設備知識庫與地端診斷助手

設備出現警報時，工程師往往需要在多份手冊中確認警報代碼、適用機型與處理條件。搜尋速度重要，但**找到的資訊是否適用、能否回查原文**，同樣重要。

這個專案以本地文件檢索為基礎，設計一套「先找資料、再驗證依據」的診斷輔助流程。

## 設計概念

1. **找到相關文件**：警報代碼等明確關鍵字使用精確搜尋；較口語的故障描述使用語意檢索。
2. **整理候選結果**：合併兩種搜尋的結果，優先呈現較相關的手冊段落。
3. **核對回答依據**：檢查來源、數值、文件適用條件與相互矛盾的資訊。
4. **證據不足時停止**：不把缺乏文件支持的操作建議當成確定答案。

簡化流程：

\`\`\`text
警報代碼或故障描述
        ↓
精確搜尋 ＋ 語意檢索
        ↓
結果整合與排序
        ↓
來源與條件檢查
        ↓
提供可回查資訊，或說明證據不足
\`\`\`

## 實作與展示

原型使用 Python、SQLite FTS5、Qdrant Local 與重排序元件。判斷來源與數值的規則集中在 [驗證程式](core/verifier.py)，避免只依賴語言模型自行判斷。

公開內容包含合成設備文件、檢索程式及測試案例。可從 [檢索測試](tests/test_mvp1_retrieval.py)、[Qdrant 測試](tests/test_sprint2_qdrant.py) 和 [套件設定](pyproject.toml) 查看實作方式。

## 適用範圍

這是**設備知識檢索與診斷輔助原型**，不是已部署的工廠控制系統。公開版本使用自編或合成資料，不包含原廠手冊 PDF，也不會直接操作 PLC／SCADA。既有測試只反映所設計的案例，不能取代設備現場驗證與工程人員判斷。
