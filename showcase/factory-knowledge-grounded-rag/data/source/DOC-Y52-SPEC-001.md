## 2. 測點訊號品質說明

- 訊號品質 (quality) 為 `good` 時方可計入閉迴路控制。
- 若出現 `uncertain` 或 `bad`，系統應切入安全防護模式，工程人員應至現場端子箱進行示波器量測。
